#  Everyday Market App

![React](https://img.shields.io/badge/React-19-blue?logo=react)
![Vite](https://img.shields.io/badge/Vite-8-purple?logo=vite)
![ESLint](https://img.shields.io/badge/ESLint-Passed-success?logo=eslint)
![License](https://img.shields.io/badge/License-Educational-orange)

This project was created for **Front-End Frameworks – Assignment 2**.

The application rebuilds the Everyday Market App using **React** and **Vite**. It displays five market categories with images, prices, and descriptions. Users can click a category to highlight it and view more details.

---

##  Assignment Requirements Completed

-  Built using React and Vite
-  Functional components
-  useState() and useEffect()
-  Mock service using Promise and setTimeout()
-  Five hard-coded market categories
- .map() used to render categories
-  Selected category state tracking
-  console.log() when a category is selected
-  Custom logo and product images
-  Polished CSS styling

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Frans-jude/Everyday-Market-React.git
cd Everyday-Market-React
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open your browser and go to:

```text
http://localhost:5173
```

##  Validation Commands
